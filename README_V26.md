# HOU-GA v26.0 — 復旧版

元のv25コードを保持して改修。重み保存・他画面連動、AI相談、地区比較、ダッシュボードは維持。

## 復旧した機能
- 地域マップ: 検証済みの地区代表点CSV（district,lat,lon）をアップロードすると地図にピン表示。座標未取得の地区は表示しない。地区境界塗分けは未実装。
- 施策シミュレーション: 仮定入力による利用希望者・人員容量・予算容量・対応可能人数・費用の自動試算、複数案比較とCSV保存。効果の因果予測ではない。
- 施策意思決定支援: 地区指標から施策候補を確認し、担当・時期・予算・人員・検証方法を登録し比較・CSV保存。
- データ管理: 独自指標CSVを地区別に結合・確認・CSV出力。総合スコアへの自動統合は未対応。

## 重要な制約
- 実データは公開資料の歴史的な数値。効果や費用・人員の仮定は公式値ではない。
- 地区代表点CSVは未同梱。根拠のない座標は生成していない。
- セッション内の比較案はCSVで保存すること。ブラウザ再起動で消える場合がある。
- 旧版のすべての機能の完全同等性は未検証。Streamlit実画面テスト・API接続テストは未実施。
- `.env`は同梱しない。アプリ直下に`OPENAI_API_KEY=...`を設定する。

起動: `pip install -r requirements.txt` → `streamlit run app.py`
