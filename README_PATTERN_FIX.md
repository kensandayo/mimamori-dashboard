# 評価パターン連動修正

- 左サイドバーは個別スライダーではなく、評価パターンを選ぶプルダウンに変更。
- 評価重み・保存ページとサイドバーで同じ `apply_pattern()` を使用し、`weight_values` を更新。
- ランキングは `utils.active_weights.scored()` から毎回現在の重みで再計算。
- 重み編集スライダーは revision ごとにキーを更新し、保存済みパターン適用時の古い値の復活を防止。
- 旧版 `data/patterns.json` にある、現在の8指標と異なるキーのパターンは削除せず未対応として明示。
- 現在の公開データ8指標に対応する標準・高齢化・介護健康・交通買い物・地域資源のプリセットを追加。

## 動作確認手順
1. 左サイドバーで「交通・買い物重視」を選ぶ。
2. ランキングで「総合スコア（保存した重みを反映）」を選び、順位とスコアを確認。
3. 「評価重み・保存」で「高齢化重視」を選び「適用」を押す。
4. ランキングに戻り、適用中の名称・順位・スコアが変化することを確認。
5. 編集した重みを名前付きで保存し、サイドバーから選択できることを確認。

※ Streamlitの実ブラウザ操作は未検証。公開ホスティングのローカルJSON保存は永続性が保証されません。
