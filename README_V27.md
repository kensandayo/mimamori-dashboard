# HOU-GA v27.0 — policy-oriented AI consultation

- AI相談に根拠付きの施策候補、実施手順、担当主体候補、追加調査事項、評価指標を追加。
- 地区別の施策候補はローカルで計算し、OpenAI APIが利用できなくても表示。
- OpenAIへは実データ・根拠付き候補を渡し、「誰が・どこで・何を・いつ・どの程度」を判断するための具体案を依頼。
- 「施策検討へ引き継ぐ」で、選択した候補を施策検討フォームに反映。
- 根拠は2021年頃の人口・R3/R4地域資源。比較は39地区内の相対指標で、支援需要・政策効果を確定しない。
- 旧版の重み保存、地図、シミュレーションなどを維持。
- .envはアプリ直下に別途配置し、ZIPには含めない。
- Python構文と提案生成のテスト済み。Streamlitの画面操作・実API接続は未検証。
