# HOU-GA v28.0 — 宇都宮市現場知識を活かすAI相談

v27.0を基に、既存の39地区分析、重み保存、施策検討、シミュレーションなどのソースを維持。

## 追加機能
- 地区別の会話履歴をSQLiteに永続保存（`local_data/city_knowledge.sqlite3`）
- 職員が地区別・全市共通の現場情報、既存施策、制約、実施結果を登録
- **承認待ち → 承認 → AI参照** のレビュー制。却下・無効化・訂正・有効期限に対応
- 地区別と全市共通の承認済み情報をAIへ渡し、根拠IDを明示して施策を再提案
- 現場制約に応じて推奨案の優先順位を変更するようAIに指示
- `.env` の `OPENAI_API_KEY` と `OPENAI_MODEL` を継続利用

## 重要な運用制限
- **この版はローカル単独利用の試作品**。ログイン・権限管理・暗号化・監査ログ・複数職員の同時編集対策は未実装。管理画面は全利用者に見えるため、市職員向け共有公開環境にデプロイしないこと。
- 会話・現場記録に個人情報、要介護者の個票、秘密情報を入力しないこと。OpenAI APIへ相談文・関連する承認済み記録・地区統計を送信する。
- 自動的なモデル再学習ではなく、保存した知識を検索してプロンプトに追加する方式。
- SQLite DBはZIPに含めない。アップグレード時は `local_data` を適切にバックアップ・移行すること。
- 公式データは過去のR3/R4頃の資料。施策の費用や効果を捏造しない。
- 実際のAPI通信、Streamlitブラウザ操作、権限管理のテストは未実施。

## 起動
```
pip install -r requirements.txt
streamlit run app.py
```
`.env` は `app.py` と同じ階層に置く。
