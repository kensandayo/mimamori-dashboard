# v31.3 dashboard drill-down

- Click a bar in the priority-score top-15 chart, a district bar in the indicator chart, a point in the scatterplot, or a bar in the expanded 39-district chart to open the district report.
- The selected district is passed through session state and automatically selected on the district report page.
- A back-to-dashboard button was added to the district report.
- The existing manual district-selection drill-down remains available.
- Requires Streamlit plotly chart point selection support.
- Browser interaction has not been tested in this build.
