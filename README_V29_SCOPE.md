# v29 分析機能整理版

- サイドバーを「ダッシュボード」（1層）、「分析」、「設定」に整理。
- 「AI相談」「施策検討」「予算・人員による施策シミュレーション」はナビゲーションから外し、コードは保持。
- 以前のデータWhat-if機能を「データシミュレーション」として追加。公式39地区CSVを読み、値の仮変更に対する見守り優先度スコア・順位の変化を表示。元CSVは変更しない。
- 地区比較、地区詳細、平均との差の色分け、アンケート分析、地図、ランキングは維持。
- 「総合スコア」「相対比較スコア」の画面表記を「見守り優先度スコア」に統一（主要表示）。
- シミュレーションは指標の相対正規化を全地区で再計算するもので、施策の因果効果予測ではない。
- 構文チェックのみ実施。ブラウザ上の動作は未検証。
