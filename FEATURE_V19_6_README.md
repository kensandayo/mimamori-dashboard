# HOU-GA v19.6 - District recommendations without interview workflow

- District selection automatically displays relative features, candidate measures, and supporting indicators.
- Candidate measures show implementation considerations (services, budgets, personnel, eligibility) rather than interview tasks.
- No interview tracking, interview targets, or interview forms are part of the district recommendation workflow.
- AI consultation and district/policy comparison pages remain available.
- Default data is demonstrative, not measured municipal data.

Run: `pip install -r requirements.txt` then `streamlit run app.py`.
